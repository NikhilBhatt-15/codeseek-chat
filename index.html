Ask any GitHub repo a question.

Paste a repo, ask in plain English, and get an answer that links to the exact lines of code. It all runs in your browser: no sign-up and no server.

How it works

  1. Reads the repo Downloads the code from GitHub and splits it into small pieces at functions and classes.
  2. Finds the right code An AI model running on your device (EmbeddingGemma 2) matches your question to the code by meaning, not just keywords.
  3. Explains it Gemini writes an answer that cites the exact lines. This step needs a free Gemini key; without one you get the matching code.

Ask from any GitHub page

Drag this button to your bookmarks bar, then click it on any GitHub repo: Ask this repo

Or install the Chrome extension, which adds an “Ask this repo” button to every repo page: download it, unzip, open chrome://extensions, turn on Developer mode and click Load unpacked. It asks for no permissions.

    Settings

    Offline AI needs no key and nothing leaves your device, but a model this small is less accurate than Gemini. It runs best on a desktop browser with WebGPU.

    Get a free key at aistudio.google.com/apikey. It's sent only to Google's API, straight from your browser.

    Advanced

    Flash Lite is the default: fast, and the free tier allows the most requests per day.

    Gemini searches, follows a function or variable to where it's defined and used, and reads more code before answering. Uses a few more API calls.

    Only needed if you index many repos: without one, GitHub allows 60 requests an hour per network, and each repo uses 2. Create a fine-grained token with Public repositories (read-only) and no permissions. It's sent only to api.github.com.

    Privacy: indexing runs locally. When you ask a question with a key set, your question and the matching code excerpts are sent to Google's Gemini API. Without a key, nothing leaves your browser except downloads from GitHub and Hugging Face.
